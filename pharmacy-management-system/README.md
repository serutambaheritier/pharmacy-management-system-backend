## Requirements

- Java 17 or later
- MySQL

## Run

1. Update the MySQL connection settings in `src/main/resources/application.properties` for your local database.
2. From the project root, run:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

3. Run the tests with:

   ```powershell
   .\mvnw.cmd test
   ```

The API collection is in `pharmacy-management-system-midterm.postman_collection.json`.
